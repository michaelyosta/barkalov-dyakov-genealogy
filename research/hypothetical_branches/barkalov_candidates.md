# Отождествления, требующие доказательств

Пунктир обозначает гипотезу. Сплошная линия означает только отношение, записанное в конкретном документе, а не установленную связь с семьёй заказчика.

```mermaid
flowchart TD
  MEMF["Отец из семейной памяти"] -. "личность не установлена" .-> MP["Михаил Петрович Баркалов — военные документы"]
  MEMM["Мать из семейной памяти"] -. "возможное совпадение" .-> AG["Антонида Григорьевна — карточка репрессированной"]
  MP -->|"жена в донесении 1942; требуется сопоставление"| AP["Антонина Прокофьевна"]
  AG -. "разное отчество; тождество не решено" .-> AP
  MP -. "братство не доказано" .-> SP["Сергей Петрович Баркалов"]
  CHILDREN["Дети из семейной памяти — данные скрыты"] -. "нет актового мостика" .-> MP
  CHILDREN -. "нет семейной анкеты" .-> AG
```

Древо доказанных прямых предков пока не может быть построено: сначала необходим исходный актовый мост. Имена/даты потенциально живых людей не воспроизводятся. См. `../claims.json`, `../relationships.json`, `../cycle_001.md`.
