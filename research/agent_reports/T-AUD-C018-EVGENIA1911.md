# T-AUD-C018-EVGENIA1911 — попытка визуальной проверки записи 1911 года

- **TASK_ID / GOAL_ID:** T-AUD-C018 / INDEPENDENT-VERIFIER.
- **Точный вопрос:** визуально прочитать ОГАОО, ф. 389, оп. 1, д. 1750, скан 182: год; декабрьскую женскую запись № 119; имя, географию, возраст, даты смерти и погребения; указано ли имя супруга; оценить только кандидатное совпадение с ранней Евгенией/первой женой 1915 года.
- **Источник для проверки:** [Яндекс Поиск по архивам, скан 182](https://ya.ru/archive/catalog/497cb38c-a23f-4be9-a86c-c6d8458e415d/182).
- **Дата попытки доступа:** 2026-11-01.

## РЕЗУЛЬТАТ ДОСТУПА

Визуально проверить скан не удалось. При первоначальной проверке `cua.getState()` браузерного интерфейса Edge в списке `browsers` не было. Попытка открыть указанный URL через браузерный инструмент веб-поиска завершилась сообщением, что ya.ru недоступен этому инструменту. Попытка проверить уже открытое окно Edge через Computer Use была остановлена самим инструментом: он не смог с достаточной уверенностью определить текущий URL окна Windows и потребовал прекратить работу с ним.

В этой попытке не получено читаемого изображения скана 182. Поэтому **год, содержание строки № 119, имя/география/возраст, даты смерти/погребения и наличие супруга остаются непроверенными**. Никакие значения OCR или ранее прочитанные оркестратором поля не представлены здесь как визуальные наблюдения.

## ГРАНИЦЫ ВЫВОДА

- Нельзя сделать положительный или отрицательный вывод о совпадении с Евгенией из брака 1899 года или о возможной первой супруге Петра, венчавшегося вторым браком в 1915 году.
- Нельзя оценить совместимость дат, возраста, места или имени супруга без прочитанного первичного изображения.
- Даже при совпадении имени/фамилии, географии или семейной роли в будущем это останется кандидатом до проверки связующего акта; тождество не объявлять подтверждённым.

## СЛЕДУЮЩИЙ ШАГ

Повторить визуальный просмотр скана 182 в доступном и надёжно идентифицированном браузере/просмотрщике. Зафиксировать заголовок страницы и полные заголовки граф вокруг строки 119, затем транскрибировать именно рукописные поля с соседними строками для контекста.
