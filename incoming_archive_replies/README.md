# Входящие ответы из архивов и органов ЗАГС (`incoming_archive_replies`)

В эту папку сохраняются полученные официальные архивные справки, выписки и скан-копии архивных дел по мере поступления ответов на 10 запросов из [`official_archive_requests.md`](../official_archive_requests.md).

## Рекомендуемый формат именования файлов

`YYYY-MM-DD_Запрос-NN_Краткое-описание.pdf` (или `.jpg`)

Примеры:
* `2026-12-05_Запрос-01_СГА-ДП-Караганда_Дело-Баркаловой-АГ-1938.pdf`
* `2026-12-10_Запрос-02_СГА-ДП-Караганда_Спецпоселение-Дьякова-К.pdf`
* `2026-12-15_Запрос-04_ИЦ-МВД-Коми_Воркутлаг-Баркалов-МП-1936.pdf`
* `2026-12-20_Запрос-07_ЗАГС-Целина_Рождение-Абросимова-КН-1932.pdf`

> **Важно:** Если в шапке ответа архива указаны паспортные данные или домашний адрес ныне живущего заявителя, перед коммитом рекомендуется заретушировать эти поля либо хранить необработанный оригинал в защищённой папке `private_kinship_docs/`.
