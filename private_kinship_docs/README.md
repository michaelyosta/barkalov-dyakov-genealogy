# Локальная папка для персональных и родственных документов (`private_kinship_docs`)

> **ВНИМАНИЕ (Безопасность):** Содержимое этой папки добавлено в `.gitignore` и **НЕ загружается в GitHub**.

Храните здесь локально (только на вашем компьютере):
1. Сканы паспортов, свидетельств о рождении, браке и смерти, подтверждающих родство с репрессированными предками (прикладываются к официальным запросам в ФСБ, МВД, ЗАГС и спецгосархивы).
2. Копии отправляемых заявлений с подставленными **реальными ФИО и точными датами рождения** лиц, рождённых в 1930-е годы (в публичных файлах репозитория они заменены на обезличенные обозначения вроде `[Потомок № 1]`, `[Потомок № 2]`, `[Потомок № 3]`, чтобы не публиковать персональные данные потенциально живущих людей в открытом GitHub-репозитории).
3. Подтверждённые семейные интервью с датой записи и именем рассказчика до их приобщения к `research/`.
